# Descrição da Aplicação / Application Description 📃

Este repositório contém o projeto de Iniciação Científica desenvolvido pela aluna Beatriz Pimenta de Camargo, sob a orientação do professor Gustavo Scalabrini Sampaio. O objetivo principal da pesquisa é explorar e compreender o funcionamento dos mecanismos de Inteligência Artificial, com foco nos fundamentos de Processamento de Linguagem Natural (NLP). Como aplicação prática, foi construído um sistema de Geração Aumentada por Recuperação (RAG - Retrieval-Augmented Generation) especializado no setor do Agronegócio. O modelo consulta um conjunto de dados do Kaggle e responde a perguntas contextuais com base nessas informações.<strong> [pt_br] </strong> 
<br>
<br>
This repository contains the Undergraduate Research Project (Iniciação Científica) developed by student Beatriz Pimenta de Camargo, under the supervision of Professor Gustavo Scalabrini Sampaio. The main objective of this research is to explore and understand the mechanisms of Artificial Intelligence, with a primary focus on the fundamentals of Natural Language Processing (NLP). As a practical application, a Retrieval-Augmented Generation (RAG) system was developed, specialized in the Agribusiness sector. The model queries a dataset from Kaggle and answers contextual questions based on that information. <strong> [en] </strong>

### Tecnologias Utilizadas / Technologies Used 💻

* [Python](https://docs.python.org/pt-br/3/) — linguagem principal do projeto
* [Jupyter Notebook](https://jupyter.org/) — ambiente de desenvolvimento
* [LangChain](https://python.langchain.com/) — orquestração do pipeline RAG
* [OpenAI API](https://platform.openai.com/docs/overview) — embeddings (text-embedding-3-large) e modelo de linguagem (GPT-3.5-turbo)
* [Pinecone](https://docs.pinecone.io/) — banco de dados vetorial
* [Pandas](https://pandas.pydata.org/docs/) — manipulação da base de dados
* [PyYAML](https://pyyaml.org/wiki/PyYAMLDocumentation) — leitura das chaves de API (config.yaml)
* [Crop Recommendation Dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset) — base de dados (Kaggle)
